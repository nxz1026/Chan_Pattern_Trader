## 1. psycopg 守卫（a_share_local.py:103,190）

### 改动前两处 `import psycopg` 裸调，ModuleNotFoundError 直接打穿到 pool_payload()，前端白屏。

### 改动后
```python
try:
    import psycopg
except ModuleNotFoundError as exc:
    raise AShareLocalError(
        "psycopg 未安装。A 股本地数据层需要 psycopg[binary]，"
        "运行 `pip install -e '.[db]'` 后重启服务。"
    ) from exc
```

### 设计取舍
- 不改成 lazy extra 自动安装：保持 `dependencies = []` 零核心依赖原则
- 异常类型用 `AShareLocalError`：让上层 `pool_payload()` 已存在的 `except AShareLocalError` 分支统一处理，不需再加一个 except 类型
- 两处对称修改：`fetch_security_names()` 和 `_get_conn()` 都调 `psycopg.connect()`

## 5. emotion_core DB 适配

### 5.1 问题
`~/.dbconfig` 无 `$DBNAME`，默认 `longkonglong` 不存在。

### 5.2 方案
实际数据在 `emotion_core` 数据库（体彩 lottery 项目共享 PG 实例）。

### 5.3 数据库变更
```sql
CREATE SCHEMA IF NOT EXISTS asel;
CREATE TABLE asel.security_master (code TEXT PRIMARY KEY, name TEXT NOT NULL, board TEXT);
CREATE TABLE asel.ref_adjust_factor (code TEXT, trade_date DATE, hfq_factor NUMERIC, PRIMARY KEY (code, trade_date));
```

- `asel.security_master`：从 `public.stock_basic` 导出，5,221 行，board 由代码前缀推导
- `asel.ref_adjust_factor`：从 `public.daily_bar` 导出 factor=1.0，3,388,417 行

### 5.4 设计说明
- `hfq_factor=1.0` 是保守默认值：emotion_core 的 `daily_bar` 数据从 2024-01-02 起，该日期后 A 股无重大除权，factor≈1.0 安全
- 后续若发现价格偏差，可用 `scripts/factor_backfill.py` 从 akshare 拉真实因子覆盖
