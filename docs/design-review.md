# CPT 规则逐项讨论框架

## 目的

CPT 逐项确定以下规则。每项讨论完成后，再将结论写入正式规则文档；在结论冻结前，不实现对应核心算法。

1. K线包含关系
2. 分型定义
3. 笔的成立条件
4. 线段的成立条件
5. 中枢的成立条件
6. 走势类型完成条件
7. 5分钟到30分钟的递归规则
8. 30分钟到4小时的递归规则
9. 4小时到日线的递归规则
10. 一买确认条件
11. 历史结构是否允许重构
12. 实时信号何时才算有效

## 当前对照结论

| 规则 | chanlun-pro 可复用程度 | 说明 |
|---|---|---|
| K线包含关系 | 高，但必须固定配置 | 有缠论K线和多种包含/分型相关配置；核心部分需结合源码与测试复核 |
| 分型定义 | 高，但必须固定配置 | 有三根/中间K线、区间和完成状态 |
| 笔成立条件 | 高 | 老笔、新笔、简单笔、顶底成笔可选；CPT 只能选定一种或明确自定义 |
| 线段成立条件 | 中高 | 有特征序列、笔破坏、缺口和中枢拆分配置；需确认与CPT规则一致 |
| 中枢成立条件 | 中高 | 标准、段内、方向、分类多种模型；需固定一个模型及区间/结束规则 |
| 走势类型完成 | 中低 | 有走势段和中枢完成状态，但没有完整独立的CPT走势完成规格 |
| 5分钟→30分钟递归 | 中低 | 有周期合成和低级别辅助高级别笔完成的机制，不等于CPT结构递归 |
| 30分钟→4小时递归 | 低 | 未证明有符合CPT定义的结构递归规则 |
| 4小时→日线递归 | 低 | 未证明有符合CPT定义的结构递归规则 |
| 一买确认 | 中高 | 有同级两中枢趋势背驰一买、三卖后背驰一买；需核对CPT口径 |
| 历史结构重构 | 中 | 有增量重建、失效和重画行为，但没有CPT统一重构政策 |
| 实时信号有效性 | 中 | 有未完成/完成/可能消失的行为，需CPT定义收盘确认和统计口径 |
